# 차량 세그멘테이션 모델 학습

AI-Hub CCTV 영상으로 차량 인스턴스 분할 모델(YOLO-seg)을 파인튜닝한 코드와 팀 전체 실험 기록.
여기서 고른 가중치가 [`traffic_project`](../traffic_project/) 에서 매 프레임 차량 면적을 재는 모델이 된다.

```
AI-Hub 원천 데이터 (분할 zip 조각 · CVAT XML 폴리곤)
   │  ① car_seg_data_preprocessing.py    YOLO-seg 라벨 + JPG + manifest
   ▼
car_seg_dataset/    25,589장 · CCTV 49대
   │  ② car_seg_data_eda.py              전체 데이터 EDA
   │  ③ car_seg_data_split.py            train 2,500 / val 1,000 / test 5,000
   ▼
car_seg_split/
   │  ④ car_seg_finetune.ipynb           학습 → 평가 → 실험 기록표에 한 줄
   ▼
best.pt  →  traffic_project/models/weights/
```

| 파일 | 하는 일 |
|---|---|
| `car_seg_data_preprocessing.py` | AI-Hub 분할 zip 조각을 디스크에 합치지 않고 가상으로 이어 읽는다. CVAT XML 폴리곤은 YOLO-seg 라벨로, PNG 는 JPG(품질 95)로 바꾸고, 이미지마다 CCTV ID · 도로 형태 · 난이도(easy/hard)를 `manifest.csv` 에 남긴다 |
| `car_seg_data_eda.py` | 샘플링 없이 모든 이미지·라벨·픽셀 밝기를 분석한다. `EDA_REPORT.md`, 속성별 통계표(CSV), 차트 18종 |
| `car_seg_data_split.py` | CCTV·클립 단위로 설계한 분할. 누수 방지 · CCTV 비율 유지 · hard 우선 train 축소 |
| `car_seg_finetune.ipynb` | 팀 6명이 같이 쓴 실험 노트북. 설정 셀만 바꿔 학습 · 평가 · 기록 |
| [`results/결과테이블.csv`](results/결과테이블.csv) | 팀 전체 실험 기록 21건. 원본 스프레드시트는 [`결과테이블.xlsx`](results/결과테이블.xlsx) (모델 담당자 시트 포함) |

## 데이터

**AI-Hub 「교통문제 해결을 위한 CCTV 교통 영상(고속도로)」** 의 폴리곤 세그멘테이션 데이터.
클래스는 `car` · `bus` · `truck` 세 개.

```
550GB  ──validation 분할만──▶  60GB  ──PNG→JPG──▶  13GB  ──분할·축소──▶  4GB
```

**정제** — 라벨 없는 이미지 524장과 이름이 같은 중복 사본 197장을 빼서 26,310장 → **25,589장** (CCTV 49대).

### 분할

| split | 이미지 | 클립 | CCTV | hard 비율 | car | bus | truck |
|---|---|---|---|---|---|---|---|
| train | 2,500 | 110 | 49 / 49 | 89% | 11,919 | 946 | 5,977 |
| val | 1,000 | 49 | 49 / 49 | 67% | 3,730 | 143 | 1,984 |
| test | 5,000 | 72 | 49 / 49 | 67% | 21,615 | 922 | 9,538 |

- **누수 방지** — 프레임을 무작위로 섞으면 거의 같은 장면이 train 과 test 에 함께 들어간다.
  그래서 CCTV 마다 val·test 용 클립을 골라 **연속 구간**을 통째로 가져가고, 나머지 프레임만 train 후보로 쓴다.
- **val · test 는 실제 분포 그대로** — CCTV 49대가 모두 들어가고, CCTV 비율과 촬영 조건(주/야간 · 날씨 · 시간대 …)
  분포가 전체 데이터와 같아지도록 클립을 고른다.
- **train 은 어려운 이미지 위주로 축소** — 처음 분할(train 20,000 / val 2,500 / test 2,500)은 데이터가 너무 많았고
  비·야간 성능이 낮았다. train 후보 19,589장에서 CCTV 비율은 유지한 채 hard 를 먼저 채워 2,500장을 골랐다
  (hard 2,219 + easy 281). bus · truck 이 많은 프레임을 우선해 bus 객체 비율을 3.2% → 5.0% 로 올렸다.
- **easy / hard** — 주간 · 맑음 · 일반 도로를 모두 만족하면 easy, 하나라도 벗어나면 hard.

## 실험

6명이 같은 노트북으로 모델과 하이퍼파라미터를 나눠 맡았다. 노트북을 한 번 돌리면 아래를 모두 하고
실험 기록표에 한 줄을 추가한다. 팀원들의 기록표를 한 폴더에 모으면 마지막 셀이 한 번에 비교한다.

1. 학습 — Ultralytics 8.4.152, COCO 사전학습 가중치에서 파인튜닝
2. val · test mask mAP
3. 조건별 mAP — 주/야간 · 날씨 · 도로 형태
4. 추론 시간 — 1장씩(batch 1), 차량 픽셀 수 계산까지 포함
5. 차량 면적비 오차 — 정답 폴리곤과 예측 마스크의 차량 픽셀 비율 MAE, 차량/배경 픽셀 IoU
   (라벨에 도로가 없어 분모는 이미지 전체)

### 관찰

- **입력 해상도가 가장 큰 변수다.** 다른 설정을 그대로 둔 YOLO26n 에서 imgsz 640 → 960 → 1280 으로
  test mAP50-95 가 0.423 → 0.561 → 0.618 로 올랐다. CCTV 속 차량 대부분이 작은 객체라 해상도의 영향이 크다.
- **1280 에서는 모델 크기 차이가 작다.** YOLO26 s → m 은 파라미터가 2.4배인데 test mAP50-95 는 +0.010.
- **bus 가 가장 약하다.** 학습 데이터 객체의 5% 뿐이다. YOLOv8n 에서 copy_paste 0.3 과 cls_pw 0.5 가
  각각 bus AP 를 0.32 → 0.35 로 올렸고, 1~4번 실험에는 둘 다 넣었다.
- **악천후가 가장 어렵다.** 기록한 세 조건(야간 · 악천후 · 터널) 중 모든 실험에서 가장 낮다
  (최종 모델 0.407, 전체 0.645).

### 최종 모델 — YOLO26s-seg · imgsz 1280

mAP 와 연산량(GFLOPs)을 함께 보고 골랐다. YOLO26m 보다 test mAP50-95 는 0.010 낮지만 파라미터는 절반 이하다
(11.4M vs 27.0M).

| 지표 (test) | 값 |
|---|---|
| mask mAP50-95 | 0.6452 |
| mask mAP50 | 0.8414 |
| AP car / bus / truck | 0.688 / 0.589 / 0.659 |
| 야간 / 악천후 / 터널 mAP | 0.689 / 0.407 / 0.721 |
| 차량 면적비 MAE | 0.35 %p |
| 차량 픽셀 IoU | 0.823 |
| 추론 | 20.2 ms/장 (49.6 FPS) |
| 학습 | 100 epoch (best 86) · 2.05 시간 |

설정: imgsz 1280 · batch 16 · AdamW lr0 1e-3 · cosine LR · cls_pw 0.5 · copy_paste 0.3 · scale 0.3 · patience 30

> 발표자료 28번 슬라이드에는 test mAP50-95 가 0.6339 로 적혀 있다. 이 문서의 수치는 실험 기록표 값이다.

## 실행

```bash
pip install "ultralytics==8.4.152" pandas matplotlib    # 노트북 첫 셀과 같은 버전

cd training
python car_seg_data_preprocessing.py --raw-root <AI-Hub 다운로드 폴더> --dry-run   # 조각 누락 · 매칭만 점검
python car_seg_data_preprocessing.py --raw-root <AI-Hub 다운로드 폴더>             # → car_seg_dataset/
python car_seg_data_eda.py                                                        # → car_seg_eda/
python car_seg_data_split.py                                                      # → car_seg_split/
# car_seg_finetune.ipynb 를 열어 실행                                              # → car_seg_finetune/
```

- 전처리는 AI-Hub 에서 받은 `download (N).tar` 를 풀지 않은 상태로도, 분할 zip 조각(`*.zip.part*`) 그대로도 읽는다.
- 노트북은 `1. 실험 설정` 셀만 고친다. 처음에는 `QUICK_TEST = True` 로 끝까지 도는지 확인한 뒤 본 실험을 돌린다.
- 노트북은 맥(MPS) 기준으로 작성했다. CUDA 장비에서는 `DEVICE` 를 `0` 으로 바꾼다.
- 데이터셋과 학습 산출물(`car_seg_*/`)은 `.gitignore` 로 제외된다. AI-Hub 데이터는 재배포할 수 없다.

학습한 가중치를 서비스에서 쓰려면 `best.pt` 를 `traffic_project/models/weights/` 에 복사하고
`traffic_project/.env` 를 맞춘다.

```bash
YOLO_WEIGHTS=models/weights/best.pt
YOLO_IMGSZ=1280        # 학습 해상도와 같게
```
